# ⚡️ Shadowrocket Node Rename Script

> **极简 · 高效 · 自动化** — 动态解析节点名称，基于地理位置与正则匹配完成标准化重命名与规范化清洗。

---

## 🌟 核心特性

* 🌍 **智能精准识别**：内置全球主要国家及地区关键词库，自动匹配并替换为 `国旗 Emoji + ISO 国家缩写`。
* 🎨 **前后缀个性定制**：支持灵活配置自定义修饰符（如特定符号、专用标记）。
* 🌐 **双语输出模式**：内置 `CN` (中文) 与 `EN` (英文) 输出标准，一键自由切换。
* 🛡️ **智能垃圾清洗**：自动识别并剔除包含“广告”、“测试”、“失效”等无效关键词的节点。
* 🏷️ **协议/业务映射**：支持自定义保留并替换传输协议或特定功能标识（如将 `HY2` 自动替换为 `GPT`）。
* 🔢 **全局去重碰撞**：内置名称去重校验机制，针对重名节点自动追加递增标识，确保节点唯一性。

---

## 🚀 快速开始

```text
[订阅管理] ➔ [点击 ⓘ 图标] ➔ [节点过滤 / Filter] ➔ [粘贴脚本] ➔ [保存]
```

1. 打开 **Shadowrocket**，进入 **订阅** 页面。
2. 点击目标订阅项右侧的 **ⓘ** 详情按钮。
3. 找到 **过滤 (Filter)** 配置选项。
4. 将本脚本全部代码复制并粘贴至输入框内。
5. 点击 **保存** 即可实时完成节点洗牌与重排。

---

## ⚙️ 核心参数配置

在脚本文件头部，可通过调整以下变量完成个性化适配：

| 参数变量 | 默认值 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| `customCharStart` | `"➥"` | String | 节点名前缀修饰符（清空 `""` 即停用） |
| `customCharEnd` | `"ᵐᵗ"` | String | 节点名后缀修饰符（清空 `""` 即停用） |
| `outputLanguage` | `"EN"` | String | 输出语言，可选 `"CN"` 或 `"EN"` |
| `filterKeywords` | `[...]` | Array | 垃圾节点过滤词库，匹配到的节点将被自动丢弃 |
| `keywordsMap` | `{...}` | Object | 功能性关键词映射字典，用于协议/业务标识替换 |

## 💡 转换效果对比

| 原始节点名称 | 脚本处理后名称 | 处理逻辑 |
| :--- | :--- | :--- |
| `洛杉矶-美国` | `➥🇺🇸USᵐᵗ` | 匹配地区映射为国旗+缩写，并添加前后缀 |
| `香港 HY2 高速` | `➥🇭🇰HK-GPTᵐᵗ` | 识别地区 + 执行 `HY2` ➔ `GPT` 协议映射 |
