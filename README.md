## 💡 为什么需要它？

`Shadow-Rocket Node Renamer` 专为追求订阅界面极致整洁的用户打造。脚本通过内置的**多国地理数据库**与**正则提取算法**，自动清洗广告节点、对齐国旗标识，并注入自定义高亮前后缀，实现节点的标准化重命名。

> <b>✨ 转换示例：</b>
> 
> `洛杉矶-HK-01-专线[测试]` ➔ **`➥🇭🇰HKᵐᵗ`**
> 
> `美国-01-HY2-高速` ➔ **`➥🇺🇸US-GPTᵐᵗ`**
